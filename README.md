# LeetCode Solutions

This repository contains my solutions to problems I have solved on **LeetCode**.

The solutions are automatically synced to this repository using the **LeetSync** extension. Each problem is stored in its own folder along with the solution and the README generated for that problem.

## Repository Structure

Each LeetCode problem has its own directory:

```text

│
```

## LeetSync

The solutions are synced automatically from LeetCode using the **LeetSync** browser extension.

The extension creates a folder for each solved problem and uploads the corresponding solution along with the problem information.

This keeps the repository updated without manually creating and uploading each solution.
